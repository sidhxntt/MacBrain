# Apple Notes Connector

## Setup

Create a controlled note with a unique title, heading, checklist item, and body
phrase. Authorize Notes automation, connect, and sync.

## Prompts

| Prompt | Pass condition |
| --- | --- |
| `What is the first checklist item in the relevant note?` | Correct checklist item with note citation. |
| `Which note contains the unique phrase?` | Correct title and openable note. |
| `What is under the unique heading?` | Correct section content only. |
| `Summarize the controlled note.` | Grounded summary with no added actions or facts. |

Edit a phrase, sync, and confirm the old phrasing cannot be retrieved as
current evidence.
