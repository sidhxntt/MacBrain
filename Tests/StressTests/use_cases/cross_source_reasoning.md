# Cross-Source Reasoning

Prepare one controlled fact in each of two or more sources, plus one deliberate
conflict.

| Prompt | Pass condition |
| --- | --- |
| `What is the complete handoff: owner, deadline, and next action?` | Combines only supported facts and cites every contributing source. |
| `Which item conflicts with the scheduled date?` | Surfaces the conflict or selects authority transparently. |
| `What changed after the meeting?` | Labels uncertainty rather than asserting an unsupported causal link. |
| `Which record supports the task mentioned in the message?` | Links only the intended controlled records. |

Fail if it silently merges incompatible information or presents inference as a
direct fact.
