# Evidence and Citations

Run after at least two controlled sources are ready.

| Prompt | Pass condition |
| --- | --- |
| `What is the exact answer?` | Each factual claim has a citation to the record that proves it. |
| `Show the evidence, not just the conclusion.` | Evidence is concise, relevant, and openable. |
| `Where did you get that?` | Follow-up identifies the exact prior source. |
| `Which source proves the date?` | Does not substitute a related but non-authoritative source. |

Fail on a missing, wrong, unrelated, stale, or unopenable citation.
